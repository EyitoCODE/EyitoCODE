# Oritse-Tsegbemi Eyito

Optical Systems & Sensors student at Carleton University, based in Ottawa.
I build software for optical imaging, inspection and engineering automation using
Python, OpenCV, PyTorch, Verilog, Tcl and Perl.

## Selected projects

| Project | What it demonstrates | Verification and scope |
| --- | --- | --- |
| [Automated Hardware Verification](https://github.com/EyitoCODE/automated-hw-verification) | Verilog simulation, Tcl automation and HTML reporting with Perl | 14 directed checks and failure-path tests; digital simulation, not physical sensor validation |
| [Opti-DefectNet](https://github.com/EyitoCODE/opti-defectnet) | Synthetic fiber imagery, a PyTorch CNN and a Gradio prototype | Disjoint train/validation/test splits and held-out metrics; real-fiber performance remains unvalidated |
| [PyOptics](https://github.com/EyitoCODE/PyOptics-Correction) | Forward lens-distortion simulation and matching rectification | Numerical regression checks on a synthetic grid; known parameters rather than measured camera calibration |
